# 于曦桌面宠物（无声版）

原生 macOS 桌面宠物，使用 AppKit 制作，无需安装第三方运行环境。

## 功能

- 透明、无边框、始终置顶，并可跨桌面显示
- 鼠标拖动角色；点击角色会挥手，睡着时点击会唤醒
- 自动散步、随机挥手、待机眨眼，长时间无互动后睡觉
- 使用 1024×1024 透明 PNG 帧序列；走路为 12 帧，起步和停步带缓入缓出
- 起步和停步各有 4 帧独立过渡；走路统一脚底基线、人物比例和头部锚点
- 走路包含轻微身体重心起伏，衣摆、长发和尾巴具有延迟惯性
- 8 帧自然待机循环：呼吸、耳朵轻抖、尾巴缓摆和眨眼
- 脚下带柔和接触阴影，随走路抬脚与落脚轻微变化
- 菜单栏狐狸图标提供唤醒、挥手、散步、睡觉、暂停和大小调整
- 当前版本不包含声音、麦克风和联网功能

## 构建

在项目根目录运行：

```bash
./DesktopPet/build.sh
```

生成的应用位于 `dist/于曦桌面宠物.app`。
